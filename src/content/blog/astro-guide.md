## 什么是 Astro？

Astro 是一个现代化的静态站点生成器，它通过独特的"岛屿架构"实现了极致的性能。

### Astro 的核心特性

1. **零 JS 运行时** - 默认输出纯 HTML，没有 JavaScript 开销
2. **岛屿架构** - 只在需要交互的地方加载 JS
3. **多框架支持** - 可以在同一个项目中混合使用 React、Vue、Svelte 等
4. **Markdown 优先** - 原生支持 Markdown 和 MDX 内容

### 快速开始

```bash
npm create astro@latest
```

就是这么简单！
